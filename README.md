# DealWheel AI

US-market web app that recommends better pre-owned vehicles for people considering a new car within a given budget.

## Deploy

Import this repo in Vercel. The build copies `public/` into `dist`, including the hero image.

Set these environment variables on Vercel. Do not commit real keys.

- AUTODEV_API_KEY
- CAR_IMAGES_API_KEY
- SUPABASE_URL
- SUPABASE_KEY
- RESEND_API_KEY
- RESEND_FROM_EMAIL
- LEAD_EMAIL
